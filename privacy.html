Privacy Policy

LexiRef for Windows and the LexiRef Word add-in · Effective 5 October 2026
In short: LexiRef is an offline app. Your reference library stays on your device. LexiRef has no accounts, no analytics, no advertising and no tracking. The only network requests it ever makes are the optional metadata look-ups you trigger yourself (Crossref and OpenAlex), and those send nothing but the identifier or search text you typed.

1. What data LexiRef stores

LexiRef stores the references, collections, tags, notes and settings you create. This data is saved locally on your device in the app's own storage (IndexedDB) and, if you choose to link a library file, in that file at the location you select. Nothing is uploaded to us or to any third party. We — the developer of LexiRef — have no access to your library.

2. Optional online look-ups

Two features need an internet connection, and both are started only by your explicit action:

FeatureService contactedData sent
Add by DOI / arXiv ID / title search, and “Refresh from DOI”Crossref REST API (api.crossref.org); for DOIs that Crossref does not know (arXiv, Zenodo, datasets) the DataCite REST API (api.datacite.org)The DOI, identifier or title keywords you typed
Integrity (retraction) checkCrossref REST API and OpenAlex (api.openalex.org), which includes Retraction Watch dataThe DOI of each reference you asked to check

These are public scholarly-metadata services. Their handling of requests is governed by their own policies. No cookies, account identifiers or device identifiers are sent with these requests. If you choose to enter a contact e-mail address in Settings (optional, for the services' “polite pool”), that address is added to these requests and to nothing else. If you never use these features, LexiRef never connects to the internet (apart from the Microsoft Store delivering updates).

3. The Word add-in

The LexiRef Word add-in runs inside Microsoft Word and reads the library file you open in it. It writes citations and a bibliography into your document only when you click the corresponding buttons. The add-in's files are delivered from our web host so that Word can load them; that host receives only the standard request information every web browser sends (such as your IP address) and does not receive your library or document content.

4. Clipboard and files

“Copy” actions place text on your clipboard at your request. Export actions create files (Word, RTF, HTML, text, BibTeX, RIS, CSL-JSON, LexiRef JSON) on your device. LexiRef never reads your clipboard or any file you did not open in it.

5. Children

LexiRef does not knowingly collect any personal data, from children or from anyone else.

6. Deleting your data

Use Settings → Delete entire library inside the app, or uninstall LexiRef from Windows; both remove the locally stored data. Library files and exports you saved yourself remain where you saved them until you delete them.
